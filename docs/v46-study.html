Independent libraries, costs, and failure interventions

This v46 study adds 11,040 evaluation episodes. Methods, library and policy seeds, and new layout IDs were fixed before these tests. Historical failures motivated the diagnostic hypotheses; this was not an independently preregistered mechanism study.

Evaluation design
StudyDesignEpisodes
ACT libraries, costs, and components2 tasks × 5 libraries × 3 policies × 20 layouts × 7 methods4,200
Meta-World libraries6 tasks × 3 libraries × 3 policies × 20 layouts × 3 methods3,240
Frozen-policy interventions2 tasks × 5 policies × 20 layouts × 2 methods × 9 conditions3,600

Source demonstrations remain fixed: 40 training and 10 development episodes per task. Library-level intervals therefore account for recovery collection and policy fitting, but not changes in the original demonstration sample.

Results and downloadable records

SCANA-R achieves 89.7% transfer and 49.7% insertion success; standard Gaussian recovery achieves 81.7% and 38.7%. The adjusted intervals do not establish a calibration advantage. Gaussian collection with longer policy training at matched total active CPU cost achieves 92.7% and 54.7%. Six-task Meta-World macro success is 89.9% for SCANA-R, 89.5% for Gaussian recovery, and 93.1% for original repetition.

Rerunning the experiments

Use the repository installation instructions and first import the original ACT and Meta-World source demonstrations and checkpoints. ACT uses MuJoCo 2.3.3; Meta-World requires a separate environment with MuJoCo 3.3.0.

# From the repository root, in the ACT environment (including pandas)
python experiments/independent_libraries_v46/experiment_v46.py all --workers 8
python experiments/independent_libraries_v46/analyze_experiments.py

# In the separate Meta-World environment
python experiments/independent_libraries_v46/metaworld_replicate.py --workers 6
python experiments/independent_libraries_v46/analyze_metaworld.py

Default output is artifacts/independent_libraries_v46. Set SCANA_V46_OUTPUT to a fresh directory for a separate replication. ACT inputs use SCANA_ARTIFACTS; Meta-World reads the existing artifacts/metaworld_extension_v1 source collection. On Windows, SCANA_ASSET_CACHE and SCANA_MW_ASSET_CACHE select writable ASCII-path caches for simulator assets.

Do not run into the frozen original evidence directory. Portable scripts adapt path bootstrapping; their hashes intentionally differ from the executed machine-local scripts. portability_manifest.json records both versions. The exported scripts were syntax-checked, but the complete reported study was not independently repeated after export.

All experiments use state observations in simulation. The results do not establish that calibration is necessary or superior at matched total CPU cost. Report every method and task, including failures.
