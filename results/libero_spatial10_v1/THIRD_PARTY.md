# Third-party sources

LIBERO source: https://github.com/Lifelong-Robot-Learning/LIBERO
Pinned commit: 8f1084e3132a39270c3a13ebe37270a43ece2a01 (MIT; see LIBERO-LICENSE.txt).
Original demonstrations: https://huggingface.co/datasets/yifengzhu-hf/LIBERO-datasets
Pinned dataset revision: f13aa24a3da8c43c7225569f28c562979fa0e35a.

This release contains new simulation recordings, error banks, recovery libraries,
model checkpoints, analysis records and project execution sources. It does not
redistribute the original HDF5 demonstration datasets, upstream mesh/texture
assets, a Python environment, or the manuscript. Obtain third-party resources
from their publishers and retain their licenses. Checkpoint tensors and numerical
arrays are preserved; a local workspace string in checkpoint metadata is replaced
by a relative study path. Source and published hashes are recorded separately.
